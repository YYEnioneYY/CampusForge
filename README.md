## О проекте

**CampusForge** — SaaS-платформа для управления командами, проектами, задачами и внутренними рабочими процессами.

Крупные компании могут позволить себе разрабатывать собственные корпоративные экосистемы, в которых объединены сотрудники, команды, проекты, задачи, чаты, документы, уведомления и аналитика. Для малого и среднего бизнеса создание и поддержка подобной системы обычно слишком дорого, а использование множества отдельных сервисов приводит к разрозненности информации и усложняет совместную работу.

CampusForge предлагает готовое единое пространство, которое могут использовать небольшие компании, стартапы, проектные команды, образовательные организации и независимые пользователи.

Платформа объединяет управление организацией и совместную работу в одном приложении:

- сотрудники и участники;
- команды и рабочие пространства;
- проекты и задачи;
- роли и права доступа;
- внутренние чаты;
- документы и файлы;
- уведомления;
- профили и навыки пользователей;
- поиск участников;
- аналитика работы команды.

При этом CampusForge предназначен не только для бизнеса. Обычный пользователь сможет создать личный проект, собрать команду, пригласить участников и организовать совместную работу без регистрации отдельной компании.

## Идея проекта

Основная идея CampusForge — сделать возможности крупных внутренних корпоративных платформ доступными небольшим организациям и самостоятельным командам.

Вместо разработки собственной дорогостоящей информационной системы компания получает готовое облачное пространство, в котором можно:

1. создать организацию;
2. пригласить сотрудников;
3. разделить их на команды;
4. настроить роли и права доступа;
5. создавать проекты;
6. распределять задачи;
7. обсуждать работу в чатах;
8. обмениваться файлами и документами;
9. отслеживать сроки и результаты;
10. анализировать работу организации.

Частные пользователи смогут использовать те же инструменты без создания полноценной организации. Например, пользователь сможет создать команду для разработки стартапа, учебного проекта, участия в хакатоне или совместной работы над личной идеей.

Таким образом, CampusForge объединяет два направления:

- корпоративное пространство для бизнеса;
- открытая платформа для самостоятельных пользователей и команд.

## Какую проблему решает CampusForge

Небольшие компании и команды часто используют сразу несколько несвязанных инструментов:

- один сервис для задач;
- другой для общения;
- облачное хранилище для файлов;
- таблицы для учёта сотрудников;
- отдельные документы для распределения ролей;
- мессенджеры для уведомлений и обсуждений.

В результате важная информация оказывается распределена между разными системами. Сотрудникам приходится переключаться между приложениями, искать сообщения и документы, вручную обновлять статусы и поддерживать порядок сразу в нескольких местах.

CampusForge создаёт единый источник информации о работе организации:

- кто входит в команду;
- кто за что отвечает;
- какие проекты выполняются;
- на каком этапе находятся задачи;
- какие решения были приняты;
- где находятся документы;
- какие события требуют внимания.

## Основные сущности платформы

### Пользователь

Каждый пользователь получает профиль, в котором может указать:

- имя и фотографию;
- описание;
- навыки;
- опыт;
- ссылки на внешние ресурсы;
- проекты;
- команды;
- портфолио.

Профиль может использоваться одновременно для работы внутри организации и для участия в независимых проектах.

### Организация

Организация представляет компанию, образовательное учреждение, сообщество или другую структуру.

Внутри организации можно:

- приглашать сотрудников;
- создавать подразделения;
- формировать команды;
- назначать роли;
- управлять правами доступа;
- создавать внутренние проекты;
- просматривать аналитику;
- управлять тарифом и лимитами.

### Рабочее пространство

Рабочее пространство объединяет людей, проекты, задачи, чаты и документы в рамках определённой команды или направления.

У одной организации может быть несколько рабочих пространств, например:

- разработка;
- продажи;
- маркетинг;
- управление;
- внутренние проекты;
- работа с клиентами.

### Команда

Команда объединяет пользователей для совместной работы.

Команда может существовать:

- внутри организации;
- внутри отдельного проекта;
- независимо от организации.

Пользователи смогут создавать временные и постоянные команды, приглашать участников и распределять роли.

### Проект

Проект содержит:

- описание и цели;
- участников;
- роли;
- этапы;
- сроки;
- доски задач;
- чаты;
- документы;
- файлы;
- историю активности.

Проекты могут быть публичными, закрытыми или доступными только участникам конкретной организации.

## Основные сценарии использования

### Небольшая компания

Компания создаёт организацию, приглашает сотрудников и распределяет их по отделам. Для каждого направления создаются рабочие пространства, проекты, задачи и внутренние чаты.

Руководитель видит текущее состояние проектов, сроки и загрузку команды, а сотрудники получают единое место для ежедневной работы.

### Стартап

Основатель создаёт команду, приглашает разработчиков, дизайнеров и менеджеров, формирует продуктовый проект и распределяет задачи.

Вся информация о продукте, задачах, обсуждениях и файлах находится в одном пространстве.

### Команда без организации

Несколько пользователей создают независимую команду для совместной работы. Регистрация компании для этого не требуется.

Команда может использовать задачи, чат, документы и управление проектом так же, как корпоративное рабочее пространство.

### Личный проект

Пользователь создаёт личный проект, ведёт список задач и хранит необходимые материалы. Позже он может пригласить других участников и преобразовать личный проект в командный.

### Образовательный проект

Студенты создают команду, добавляют преподавателя или наставника, распределяют задачи и работают над учебным, исследовательским или дипломным проектом.

Образовательная деятельность остаётся одним из возможных сценариев использования платформы, но не ограничивает её назначение.

## Принципы CampusForge

### Доступность

Платформа должна быть доступной для небольших компаний и команд, которые не могут позволить себе разработку собственной корпоративной системы.

### Единое пространство

Пользователю не требуется собирать рабочий процесс из большого количества отдельных приложений.

### Гибкость

Команды и проекты могут существовать как внутри организации, так и независимо от неё.

### Модульность

Организация сможет использовать только необходимые ей возможности и постепенно подключать новые модули.

### Безопасность

Платформа предусматривает:

- разграничение прав доступа;
- управление активными сессиями;
- отзыв токенов;
- подтверждение email;
- журналирование важных действий;
- защиту персональных данных;
- приватные организации, команды и проекты.

### Масштабируемость

Архитектура позволяет постепенно добавлять новые сервисы и развивать платформу по мере роста количества пользователей и организаций.

## Архитектура

CampusForge разрабатывается как микросервисная система с единой точкой входа через **API Gateway**.

```text
Frontend
   |
API Gateway
   |
   |-- Auth Service
   |-- Profile Service
   |-- Reference Service
   |-- Access Service
   |-- Organization Service
   |-- Team Service
   |-- Project Service
   |-- Task Service
   |-- Chat Service
   |-- Notification Service
   |-- Subscription Service
   |-- Media Service
   |-- Search Service
   |-- Analytics Service
   |-- Moderation Service
   |-- Admin Service
```

Внешнее взаимодействие клиентов с платформой:

```text
REST API + WebSocket
```

Внутреннее взаимодействие сервисов:

```text
Kafka request-response + integration events
```

Основные принципы архитектуры:

- API Gateway является единой внешней точкой входа;
- каждый сервис отвечает за отдельную предметную область;
- сервисы используют собственные базы данных;
- Kafka используется для запросов и событий;
- Redis используется для кеширования и оперативного состояния;
- MinIO используется как S3-совместимое файловое хранилище;
- WebSocket обеспечивает обмен сообщениями и обновления в реальном времени.

## Модель распространения

CampusForge развивается как облачная SaaS-платформа.

Предполагается несколько вариантов использования:

- бесплатное личное пространство;
- бесплатные небольшие команды с базовыми лимитами;
- тарифы для компаний;
- расширенные возможности для организаций;
- дополнительные объёмы файлового хранилища;
- расширенная аналитика;
- корпоративные настройки и интеграции.

Базовые возможности позволят пользователям познакомиться с платформой и начать работу без сложного развёртывания и крупных первоначальных затрат.

Цель CampusForge — создать доступную альтернативу дорогостоящим внутренним корпоративным системам и объединить в одном продукте:

- управление организацией;
- работу команд;
- ведение проектов;
- управление задачами;
- внутреннюю коммуникацию;
- хранение файлов;
- профили пользователей;
- поиск специалистов;
- уведомления;
- аналитику.

Платформа должна подходить как компаниям, которым требуется готовая цифровая рабочая среда, так и обычным пользователям, желающим собрать команду и организовать совместную работу над собственной идеей.
